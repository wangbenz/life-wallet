## Project Overview

Life Wallet（人生账单 / 人生存钱罐）是一个 AI 人生理解系统。它用“每天消耗 1 元人生”的账户化表达，帮助用户直观看见自己的时间不是无限的，并通过自然语言或语音记录一天，让 AI Agent 自动完成分类、统计、分析和反馈。

## Current Stage

当前阶段：Product Discovery（产品发现）。

本阶段重点不是写代码，而是明确：目标用户、使用场景、核心痛点、现有替代方案、产品机会、关键假设和验证问题。
