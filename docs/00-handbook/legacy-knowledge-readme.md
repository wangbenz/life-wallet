# Life Wallet Knowledge Base

This directory is the single source of truth for the Life Wallet / 人生存钱罐 project.

## Documents

- `product-discovery-v0.1.md`: Product Discovery notes, core hypothesis, current exploration, and provisional consensus.
- `discovery-decisions.md`: discovery-stage decisions.
- `discovery-questions.md`: open questions for Product Discovery.
- `life-ontology.md`: working draft for the Life Ontology model.

## Working Rule

Product understanding comes before implementation. When the product model changes, update `knowledge/` first, then update code.
