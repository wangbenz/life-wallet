# Open Questions

## 1. 人生“质量”如何定义？

- 是否需要评分体系？
- 是否引入满意度？
- 评分是否会伤害产品的温和感？

## 2. Domain 演化规则

- 何时新增 Domain？
- 何时合并 Domain？
- 是否允许 AI 自动生成？
- 是否需要人工审阅或用户不可见的后台审阅？

## 3. Memory 系统设计

- 短期记忆和长期记忆如何分层？
- 哪些信息可以进入长期记忆？
- 是否生成“人生画像”？
- 记忆是否需要可编辑、可删除、可解释？

## 4. Agent 是否主动建议行为？

- 是否引入人生建议系统？
- 建议应该是主动出现，还是用户询问后出现？
- 建议边界如何避免说教感？

## 5. 产品长期价值

- 用户为什么会持续使用？
- 每日记录后，用户立刻获得什么回报？
- 一周、一个月、一年后，系统给用户什么独特价值？
