# Delivery Roadmap

Status: Active
Last Updated: 2026-07-24
Owner: Human + Codex

## 已完成

### Milestone 1-5：H5 核心闭环

- 前后端项目骨架和健康检查。
- 人生账户、Today 记录、规则版轻量 Agent 和最近记录 API。
- Activity 提取、分类、时长估算、总结和结构校验。
- Today 记录提交、分析、保存与 Life 最近记录展示。

### Milestone 6A：独立前端验证版

- 前端切换为 Mock + `localStorage`，不依赖后端。
- Today 完成自然语言记录、预览编辑、确认保存和准确度反馈。
- Life 收缩为真实记录驱动的“洞察 / 记录”。
- Me 收缩为账户、数据管理、隐私和反馈。
- 删除假趋势、成就、连续打卡、假统计和无功能入口。
- 完成原型风格回归、Lucide 图标、轻量微交互和移动端检查。
- Mock 测试与生产构建通过。

### Milestone 6B：测试环境

- 京东云安装并启用 Nginx。
- H5 生产包部署到 TCP `15173`。
- 服务器本机与公网访问验证通过。
- Nginx 配置纳入 `deploy/nginx/life-wallet.conf`。
- 发布、验证和回滚流程写入 `docs/03-delivery/02-operations.md`。

### Milestone 7A：真实 Life Agent vertical slice

- 新增 DeepSeek Chat Completion / Tool Calling 模型适配，密钥只从服务端环境变量或 secret 文件读取。
- 实现最多 4 步的自定义 Agent Runtime、白名单 Tool；会话和 `clientTurnId` 幂等已进一步迁移到 JDBC。
- 实现记录查询，以及新增、修改时长、删除三类待确认动作；写 Tool 不直接修改业务数据。
- H5 Life Agent 接入真实后端，每轮只发送最多 20 条必要记录字段。
- Today 与 Life Agent 增加浏览器语音转文字，并保留文字输入兜底。
- 后端 Runtime / 模型协议测试和前端 Agent API / 构建验证通过。

### Milestone 7B：数据库结构基础

- 引入 Spring JDBC、Flyway、MySQL Connector 和本地 H2 开发数据库。
- 新增账户、记录、活动、维度汇总、记录反馈、体验反馈、Agent 会话和轮次 8 张业务表。
- 增加外键、唯一键、范围约束、状态约束和高频查询索引。
- 新增 MySQL 8.4 本地/服务器 Compose 基础设施，并限制数据库只监听本机。
- 增加迁移、约束和级联删除自动化测试。
- 账户、记录和 Agent 会话 Store 切换到 JDBC，服务重启后仍可读取。
- H5 为新安装生成随机 `ownerKey` 并随 Agent 请求发送，不导入历史 `localStorage` 数据。
- “清除数据”同步调用后端删除接口；服务不可用时只清本机并明确提示后端未确认删除。

### Milestone 7C：H5 全数据链路接通

- 账户初始化与修改切换到 `/api/account`。
- Today 使用“后端预览但不落库 → 用户编辑确认 → JDBC 保存”的两阶段接口。
- 手动和 Agent 发起的覆盖修改、删除统一调用受控记录 API。
- Life 历史、准确度反馈、体验反馈、导出和清除全部切换到后端数据。
- H5 只在浏览器保存匿名 `ownerKey`，不迁移旧 `localStorage` 业务数据。
- 后端 25 项测试、前端 14 项测试和生产构建通过；真实 HTTP 闭环验证通过。

## 当前任务：Agent 集成验证

1. 使用轮换后的 DeepSeek 密钥在本地验证真实模型的查询、新增、修改、删除和越界拒答。
2. 建立固定中文样例集，记录 Tool 选择、参数、写前确认和最终回复问题。
3. 为测试环境增加后端进程托管、Nginx `/api` 反向代理和 HTTPS；HTTP 公网 IP 不作为语音验收环境。
4. 验证服务不可用、模型超时、浏览器不支持语音和用户拒绝麦克风权限时的文字兜底。
5. 不在本阶段增加数据库、登录、复杂 Memory 或更多页面。

## 随后的用户验证

开始邀请无主持用户前，先完成 2026-07-23 H5 产品审计收敛：

1. 首次开户不使用假默认生日，开户完成后自动进入 Today。
2. Today 预览自动定位、显示原句来源，并确保确认操作不被底部导航遮挡。
3. Life 低样本洞察弱化精确画像，历史记录收拢次要操作。
4. Agent 返回文案、快捷问题和输入提示跟随来源与目标记录。
5. 本地反馈支持复制带出，明确团队不会自动收到。
6. 主要日期、信息和记录操作达到 44px 触控目标。

1. 邀请 5-10 个目标用户。
2. 每位用户完成 7 个记录日，而不是要求连续自然日。
3. 收集记录耗时、解析准确度、时间反馈理解度和回访意愿。
4. 汇总最常见的修改原因和放弃节点。
5. 根据证据调整核心闭环，不增加无验证价值的页面。

验收：

- 至少获得 5 位目标用户的有效体验反馈。
- 可以判断记录成本、AI 理解可信度和第 7 个记录日反馈是否成立。
- 明确下一轮是继续当前本地优先 Agent、增加服务端持久化，还是暂停该方向。

## 后续候选任务

仅在用户明确要求时推进：

- 完善真实模型固定样例评估、精简 trace、成本与延迟观测。
- 需要跨用户反馈时增加鉴权和服务端持久化。
- 根据验证结果评估微信小程序，而不是直接迁移全部 H5 页面。

## 暂不进入

- 完整微信小程序。
- 登录、多用户权限和支付。
- 周报 / 月报、复杂 Memory、RAG 和向量数据库。
- 社交、排行榜、打卡奖励和心理治疗能力。
