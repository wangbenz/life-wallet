## Archive

`archive/` 保存 Idea、Discovery、旧 MVP、编码准备度、决策日志和方法论。它们只用于追溯为什么做过某个决定，不应覆盖活跃文档中的当前结论。

新增结论优先更新现有事实源，不为一次讨论新建独立文档。
